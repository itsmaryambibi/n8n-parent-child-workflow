# Parent–Child Workflow in n8n

## About the Project
This is a beginner practice project exploring Parent and Child Workflows in n8n.

The Parent Workflow calls a separate Child Workflow to perform a task and receives the result.

## How It Works
1. The Parent Workflow receives a request.
2. It calls the Child Workflow.
3. The Child Workflow processes the request.
4. The result is returned to the Parent Workflow.

## Tools Used
- n8n
- OpenWeatherMap API

## What I Learned
- How workflows communicate with each other.
- How to pass data between workflows.
- How to use reusable workflows in automation.
